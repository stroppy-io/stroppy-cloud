# Живая проверка восстановления через сервер

Suite `7af25d36-2e74-4165-a314-2f9e80f9177d`, реальный YC, Graphene 0.2.25.
[Итог проверки](verification.json), [события наблюдения](observations.json).

- Недоступность Graphene до admission: сервер отказал на проверке квот с 503,
  suite-run не создал. Повтор после восстановления с тем же Idempotency-Key
  запустил suite; следующий повтор вернул тот же ID.
- Во время SQL-нагрузки PostgreSQL соединение server→Graphene разорвано на
  30 секунд, локальный сервер перезапущен. Прокси зарегистрировал 165 отказов
  соединений; после восстановления сохранились ID suite, обеих server rows и
  ссылки Graphene run. Реальная потеря ответа уже принятого StartRun отдельно
  не инжектировалась: её покрывают интеграционные тесты.
- PostgreSQL завершил 120 секунд SQL-проверки config: 493387 запросов, ноль
  ошибок. Получены 61 native series, host-метрики обеих машин и 73 PostgreSQL
  exporter series, логи и facets. Конфиг и лог скачаны, размер/SHA совпадают.
- Keep PostgreSQL истёк автоматически: deadline 16:05:33 UTC, подтверждена
  полная очистка к 16:08:03 UTC. TTL запускает каскад удаления, а не означает
  мгновенное исчезновение всех ресурсов. Артефакты остались доступны.
- Noop-ячейка намеренно отменена во время deploy при повторяющемся таймауте
  pull. Cancel RPC отправлен при недоступном Graphene: HTTP 503, в БД сохранён
  cancelling. После восстановления наблюдатель сам доставил отмену, конечный
  статус cancelled; инфраструктура удалена. Workload этой ячейки **не проверен**.
- Повторное получение свежих квот после рестарта работает без ручной замены
  реквизитов. Обновление IAM-токена внутри многчасового сегмента этим не доказано.

Тестовый прокси остановлен, Compose возвращён к прямому TLS-соединению.
Cleanup проверяется по серверному дереву Graphene; независимый запрос YC не
выполнялся. Temporal execution UUID этим API не раскрывается — утверждение о
тождественности здесь относится к server IDs и Graphene run references.

Скрипты: `live/tools/server_resilience_live.py`, `graphene_fault_proxy.go`,
`record_resilience_checks.py`, `verify_server_{cleanup,telemetry,artifacts}.py`.
Результаты внесены в единую `live/tests/progress.csv`.
