# IAM rotation: первая попытка

Run `608b7c66-56d7-4c35-8559-800c056a953e` завершён failed, cleanup прошёл.
Managed YDB ready подтверждён деревом ресурсов; начальный вход Stroppy с
токеном из файла прошёл. Через минуту activity оборвалась с
`read stroppy logs: context canceled`, ротация ещё не наступила.

Причина в коде пайплайна: первый heartbeat из проверки версии использовал
контекст краткого probe. Temporal сохраняет этот контекст для отложенного
heartbeat; после cancelProbe следующий batch отменил всю activity.
Исправление привязывает heartbeat к исходному контексту activity, сохраняя
отдельный timeout операций. Родительская отмена/deadline продолжают действовать.
Исходники Graphene не менялись. Нужен полный новый прогон, не resume.
