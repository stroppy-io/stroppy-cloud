# Контроллер HA с поддержкой PostgreSQL

Расширение [контроллера MySQL/Galera](../ha-failover-probe-20260927/README.md)
использует pgx и PostgreSQL SQL-диалект. Определяет обслуживший запись узел
по `inet_server_addr()`, после восстановления проверяет ровно один primary.
Границы управления Docker и сравнение строк сохраняются.

[Источник, бинарник и digest](image.json), [локальные проверки](validation.json).
Это тестовый контейнер; сервер, пайплайны и Graphene не меняются.
