# Контроллер Patroni с ожиданием первой успешной операции

`image.json` фиксирует опубликованный digest, source/binary SHA. Точный
исходник сохранён в `source-changes.tar.gz`; исполняемый инструментарий —
в `live/tools`. Контроллер использует Docker только своей одноразовой VM:
цель и сам probe должны иметь одинаковую непустую метку run и точное
логическое имя контейнера. Проверки принадлежности прошли с race detector.

После появления control.started=1 контроллер выполняет stop/start выбранного
primary и сравнивает все поля контрольных строк через SQL каждой реплики.
При ошибке предусмотрен возврат остановленного контейнера. Источник разрешения
на этот fault — согласованная живая проверка отказов тестовых топологий.
