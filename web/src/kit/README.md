# Stroppy UI kit

How Stroppy looks, independent of any framework: everything here is read by
the app, and will be by a report page or a site, after the kit moves to
`stroppy-ui`. Adapters to a framework (the Grafana theme, a site's CSS
mapping) live with whoever uses that framework, not here.

| File | What |
|---|---|
| `tokens.json` | The source: palette for dark (graphite) and light, fonts, sizes, radii, spacing, the mark orange. |
| `tokens.ts` | Typed access to the tokens. |
| `tokens.css` | The tokens as `--st-*` variables; dark unless `data-theme="light"`. Generated by `css.ts`: change `tokens.json`, then `KIT_UPDATE=1 yarn test`. |
| `base.css` | Plain HTML inside `.st-doc`, plus opt-in hooks for meaning (below). |
| `fonts.css`, `fonts/` | Inter and Roboto Mono. |
| `logo.ts`, `logo/mark.svg` | The mark: geometry, and the same as an SVG that takes `--st-mark` (rays, band) and `--st-muted` (cylinder). |
| `chart.ts`, `chart.css` | A time-series chart that looks like the app's Grafana panels, drawn by uPlot on the `--st-*` variables. |
| `example.html` | A report page on the bundle: which files to link and how to mount a chart. |

`base.css` hooks, all CSS on the tokens:

| Markup | What it gives |
|---|---|
| `data-tone="success\|warning\|error\|info\|primary\|muted\|mark"` | Meaning: text-level elements and table cells take the colour; the shapes below use it for border, tint, dot. |
| `data-series="1".."8"` | Chart series colour for a legend entry, dot or bar (`--st-series-N`). |
| `.st-tag`, `.st-tags` | A label in a pill; a wrapping row of them. |
| `.st-dot` (`data-pulse`) | A status light; pulsing while something runs. |
| `<aside>` / `.st-callout` | A note; a first `<strong>` is its title. Info unless `data-tone` says otherwise. |
| `.st-stat` in `.st-grid` | A headline number: label, `<strong>` value with `<small>` unit, a note. |
| `.st-panel` with `<header>` | A bordered block with a title row; a table inside goes edge to edge. |
| `.st-grid`, `.st-row` | Equal responsive columns; a wrapping row. |
| `<dl>` | Key–value in two columns. |
| `tr[data-tone]`, `.st-bar` (`--value: 62%`), `table.st-compact` | A tinted row, an inline share bar, denser cells. |
| `<progress>`, `<meter>` | Thin tracks in our colours. |
| `.st-button` (`data-variant="primary\|text"`) | A link or button that is an action. |
| `<nav>` links (`aria-current`), `<details>`, `<mark>`, `<abbr title>` | Pills, a disclosure, a highlight, a dotted hint. |

## Chart

`mount(target, series, { unit, height })` draws series shaped like a run's
metrics (`{ title, unit, points: [[time, value], …] }`, time in seconds or
milliseconds): 1px smooth lines with an 8% fill, the series colours, a quiet
grid, 24-hour time labels, a legend under the plot and a tooltip. It follows
its width and the nearest `data-theme`. In the bundle it is
`StroppyChart.mount(...)`.

## Bundle

`yarn build:kit` (or `make kit-bundle`) writes `web/dist-kit/stroppy-kit/` and
`stroppy-kit-<version>.tar.gz`: `tokens.json`, `tokens.css`, `fonts.css` with
`fonts/`, `base.css`, `logo/`, `chart.js` (uPlot and `chart.ts` as one script
without modules, exposing `window.StroppyChart`), `chart.css` (uPlot's
stylesheet and ours), `example.html`, `VERSION`. A release attaches the
archive; the version is the release's. A single-file report inlines these
files instead of linking them.

Rules: nothing here imports outside the folder except `uplot` (biome enforces
it; tests may use `node:` and `vitest`). A component joins the kit only when two users
need the same non-trivial markup. The showcase is `/kit` in a dev build.
